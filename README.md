# fCpG_Mitotic_Clock
Code for “Early Colorectal Growth Is Often Slow Rather Than Exponential

Overview

This repository contains Python programs used to simulate colorectal
cancer (CRC) growth histories and rapidly fluctuating CpG (fCpG)
methylation patterns for approximate Bayesian computation (ABC).

The programs form a sequential workflow. Program1 generates candidate
tumor growth histories. Program2 uses the output files generated by
Program1 to construct cell-number histories with spatial gland splitting
and terminal Phase 5 options. Program3 then uses the Program2 output to
simulate fCpG methylation and calculate summary statistics for
comparison with experimental CRC gland methylation data.

Files

Program1.py

Generates the candidate tumor growth trajectories used as the starting
input for the subsequent simulations.

Growth is represented by division outcomes in which cells may remain as
one cell, divide into two cells, or be lost. Parameters are varied
across phases to generate alternative candidate growth histories.

The output CSV files from Program1 are used directly as input by
Program2.

Output: Candidate growth-trajectory CSV files.

Program2.py

Uses the candidate growth-trajectory CSV files generated by Program1 and
converts them into cell-number tables used by the fCpG simulation.

The script: - generates sequential tumor population histories, -
introduces spatial splitting events used to model multiregional gland
sampling, - assigns early, middle, or late gland-splitting
configurations, and - optionally adds a terminal Phase 5 representing
continued cell turnover after net tumor expansion has stopped.

Output: Cell-number tables describing the population size, cell-division
outcomes, spatial gland splitting, and terminal growth phase for each
simulated growth history.

Program3.py

Uses the cell-number tables generated by Program2 to simulate fCpG
methylation along the candidate tumor growth histories.

The simulation tracks methylation changes during cell division,
reconstructs spatially separated glands, and calculates summary
statistics including: - individual gland fCpG variance, - overall fCpG
variance, - within-side gland correlations, - between-side gland
correlations, and - early lineage/barcode representation.

These statistics are used for ABC comparison with experimental CRC gland
methylation data.

lookup5_table.csv

Lookup table containing the starting fCpG states and
methylation/demethylation transition probabilities used by the fCpG
simulation.

Workflow

The programs are run sequentially:

1.  Program1.py Generate candidate growth trajectories.

              |
              v

2.  Program2.py Use the Program1 output to generate cell-number and
    spatial gland-splitting tables, including terminal Phase 5 variants.

              |
              v

3.  Program3.py Use the Program2 output to simulate fCpG methylation and
    calculate ABC summary statistics.

The resulting simulated summary statistics can then be compared with
experimental CRC fCpG measurements to identify growth histories
consistent with the observed data.

Requirements

Python 3

Python packages: - NumPy - SciPy

The scripts also use standard Python libraries including csv, os,
random, itertools, and re.

Reproducibility

These programs are the simulation programs used for the analyses
described in the manuscript.

The simulations are stochastic. Individual simulation runs therefore
will not produce identical trajectories unless random-number seeds are
specified. The analyses described in the manuscript rely on
distributions across large numbers of independently simulated tumor
histories rather than on individual simulation runs.

Data

Experimental methylation and sequencing data used in the manuscript
should be obtained from the sources described in the manuscript and its
Data Availability statement. Controlled-access or patient-level data are
not included in this repository.
